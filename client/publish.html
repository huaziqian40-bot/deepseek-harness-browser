📦 把它装到任何 Harness

这个共享浏览器是一个可分发插件 —— 下载 ZIP，任何 dsh harness 解压即用，获得同样的全部特性

⬇️ 插件包

下载 dsh-tool-browser-2.1.0.zip
版本 2.1.0 · 包含服务端 + 客户端 + 发布页 + README + 清单
元数据：manifest.json · 文档：README.md

🛠️ 安装（一条命令 ⭐）

curl -sL https://你的主机/plugin/install.sh | bash -s https://你的主机

脚本自动定位 ~/.dsh/profiles/web、下载解压插件、写入 cordis 补丁并尝试重启 dsh-web；若存在 systemd 服务则自动重启。有头模式依赖 Xvfb + chromium + fonts-noto-cjk，缺失时仅提示。

🛠️ 手动安装（3 步）

unzip dsh-tool-browser-2.1.0.zip \ -d ~/.dsh/profiles/web/plugins/ # 可选：有头模式（推荐） apt-get install -y xvfb fonts-noto-cjk Xvfb :99 -screen 0 1600x1000x24 -ac & # 服务加 DISPLAY=:99 后重启 dsh web

可选在 web profile 补丁中调整 viewportWidth / frameQuality / frameIntervalMs； 重启后打开 /publish 即可。控制通道走 token+HMAC 鉴权，发布页/下载为匿名静态资源。

三步开始使用

无需安装，无需登录账号，浏览器即可

打开面板

点击页面右下角的 🌐 悬浮按钮，展开共享浏览器面板。

启动浏览器

点击 ▶ 启动，云端会拉起一台有头 Chromium（也可让 AI 通过 browser_launch 启动）。

直接操作

在画面上点击、拖动、滚动、输入，或在上方地址栏打开任意网址 —— 画面实时同步，操作即时反馈。
